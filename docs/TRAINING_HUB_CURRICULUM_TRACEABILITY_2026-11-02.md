## Competency crosswalk

- Account correctness: policy version, normalized source username, created identifier, originating request, actual game account and Backend confirmation.
- Customer verification: exact subject/player match plus company/license context where supported. A game name is not a substitute for licensed-access evidence.
- Financial safety: request balance, live relevant balance, reservations, game history, Backend decision and no duplicate posting.
- Credential safety: actual reset evidence and provided/matched flags; never a retained password literal.
- Exception handling: observed operation/history evidence, permitted decision and required reason; a reconciliation answer must not execute another movement.
- Readiness: exact curriculum/evaluation/adapter versions, original numerical results, official submission, reopening history and private staff review. Readiness is for onsite training, not independent job certification.
